## 🛠️ 环境配置

### Q：为什么 Rider 打开 YooAsset.cs 没有高亮、跳转不到定义？

**原因**：Rider 需要通过 Unity 生成的 `.sln` 打开项目，直接打开文件夹只是普通 C# 项目，没有程序集引用信息。

**修复**：
1. `Unity → Edit → Preferences → External Tools` → 选 Rider
2. 点 `[Regenerate project files]` 生成 `.sln` / `.csproj`
3. 用 **`Unity → Assets → Open C# Project`** 打开（不要用 Rider 的 Open Folder）
4. 打开后左下角应显示 "Unity Editor (已连接)"

---

### Q：Unity 应该打开 YooAsset 根目录还是 Sample 目录？

打开 **`/LearnYooAsset`（项目根目录）**。

- `Assets/YooAsset/` 是嵌入的 YooAsset 源码
- `Samples~` 的 `~` 是 Unity 约定的"忽略目录"，不会被编译
- 想跑 Sample 要把目录**复制**到 `Assets/` 下，Unity 才会编译

---

### Q：Rider 文件管理器为什么看不到根目录的 .md 文件？

Solution 视图只显示 `.csproj` 里登记的代码文件。

**切换到 File System 视图**（Project 面板顶部的下拉）就能看到全部文件，包括 `CLAUDE.md`、`AI-Learning/*.md` 等。

## 🎮 资源加载

### Q：`handle.Release()` 和 `sceneHandle.UnloadAsync()`，是一个同步一个异步吗？

**不是设计偏好问题，是底层操作的耗时决定的**。

| Handle 类型 | 卸载 API | 同步/异步 | 原因 |
|------------|---------|---------|------|
| AssetHandle / RawFileHandle / SubAssetsHandle / AllAssetsHandle | `Release()` | 同步 | 只改引用计数，几纳秒 |
| **SceneHandle** | **`UnloadAsync()`** | **必须异步** | Unity `SceneManager.UnloadSceneAsync` 本身异步；销毁几千个 GameObject 一帧做不完 |

**易踩的坑**：`SceneHandle` 不要调 `Release()`！`UnloadAsync()` 内部已经自动帮你做了 `Release` 的事（源码注释写明了）。

**类比**：这和 C++ 做资源系统的思路一样 —— 轻量操作立即返回，重量操作必须 async/callback。

### Q：SubAssetsHandle 加载图集里的图片好复杂，所有 UI 图片都要这样用吗？我在 Prefab 拼的 UI 也要写代码 load .png 吗？

**95% 的 UI 场景不需要碰 `SubAssetsHandle`**。

#### ✅ 场景 A：静态引用（绝大多数 UI 情况）

直接在编辑器里拖拽 sprite 到 Prefab 的 Image 上：

```csharp
// 运行时只需要加载 Prefab
var handle = package.LoadAssetAsync<GameObject>("UIHome");
yield return handle;
var ui = handle.InstantiateSync(canvasRoot);
// 完事！所有 sprite 自动显示，不用管！
```

**原理**：Prefab 对 Sprite 的引用是**序列化的 GUID 引用**。打 AB 包时 YooAsset 自动分析依赖（`UIHome.prefab → Atlas.spriteatlas → icon.png`），写进 Manifest。运行时加载 Prefab，框架自动加载依赖 Bundle。

#### ⚠️ 场景 B：动态换图（才需要 `SubAssetsHandle`）

运行时才知道要显示哪张图的情况：

```csharp
// 例：玩家等级变化 → 切换头像边框
var handle = package.LoadSubAssetsAsync<Sprite>("Assets/UI/AvatarFrames.png");
handle.Completed += h =>
{
    var sprite = h.GetSubAssetObject<Sprite>($"frame_level_{level}");
    avatarImage.sprite = sprite;
};
```

#### 🎯 判断标准

| 情况 | 用什么 API |
|------|-----------|
| 编辑器能拖的（UI 布局固定）| **啥都不用**，只加载 Prefab |
| 玩家数据驱动的图（头像、徽章、皮肤） | `LoadSubAssetsAsync` |
| 独立的 Sprite 文件（不在图集里）| `LoadAssetAsync<Sprite>` |

#### 💡 Bundle 依赖的天然限制

Bundle 是加载的最小单位，**不能只拉 Bundle 的一部分**。

后果：如果一个 2048×2048 的图集 Bundle 包含 100 张 icon，你的 Prefab 只用了 1 张，加载 Prefab 也会把整个图集 Bundle 拉进内存。

**优化策略**：
- 同一界面用到的图放同一个图集
- 大 UI 按模块拆图集（HomeAtlas / BattleAtlas / SettingsAtlas）
- 小 UI 用零散图片 + `LoadAssetAsync<Sprite>` 精确加载
