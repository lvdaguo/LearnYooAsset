# Quiz · 测验说明

每章对应一份 `XX-XXX-测验.md`，答题流程：

1. **阅读对应章节** → 关闭文档
2. **打开测验 MD** → 在每道题的 `## 我的答案` 下面作答
3. **告诉 AI**："批改 03 测验" 或 "帮我看看 02 测验"
4. AI 会直接在文件的 `## AI 批改结果` 部分给出评分与指正

## 作答原则

- **不会的直接写"跳过"** → AI 会给参考答案并重点讲解
- **可以写错** → 错了才知道哪里理解偏了
- **用自己的话写** → 不用背文档原文，说出意思就行
- **代码题写伪代码也行** → 重点是思路对不对

## 每份测验的内部结构

每份测验做完批改后的结构：
```
Q1 题目
   → 我的答案（你写的）
   → AI 批改结果（具体分数 + 错在哪）
   → 📖 Q1 标准答案（可快速复习用）

Q2 题目
   → ...
```

批改和标准答案是**逐题内联**的，方便扫读。

## 推荐学习节奏

```
读一章 → 做一章测验 → AI 批改 → 根据错题回看文档 → 进入下一章
```

不要一次读完全部再做，容易前后混淆。
