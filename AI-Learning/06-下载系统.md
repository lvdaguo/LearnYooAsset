# 06 · 下载系统

## 下载器概览

下载系统的核心类是 `ResourceDownloaderOperation`（继承自 `DownloaderOperation`），它负责管理一批 Bundle 文件的并发下载。

**最大并发数**：代码中硬限制 `MAX_LOADER_COUNT = 64`，创建时会 Clamp 到 [1, 64]。

---

## 创建下载器的三种方式

### 方式 1：下载整个包的所有缺失资源

```csharp
// downloadingMaxNum：同时下载文件数
// failedTryAgain：失败重试次数
var downloader = package.CreateResourceDownloader(
    downloadingMaxNum: 10,
    failedTryAgain: 3);
```

### 方式 2：按标签下载（分包、DLC 场景）

```csharp
// 下载带有 "level1" 标签的所有资源
var downloader = package.CreateResourceDownloader(
    tags: new string[] { "level1", "ui_common" },
    downloadingMaxNum: 10,
    failedTryAgain: 3);
```

### 方式 3：按资源地址下载指定资源

```csharp
AssetInfo[] assetInfos = package.GetAssetInfos("level2"); // 通过标签获取资源列表
var downloader = package.CreateBundleDownloader(
    assetInfos,
    downloadingMaxNum: 10,
    failedTryAgain: 3);
```

## 下载器属性（开始下载前读取）

```csharp
// 需要下载的文件总数（== 0 表示已是最新，无需下载）
int totalCount = downloader.TotalDownloadCount;

```

## 回调注册（在 BeginDownload 前注册）

```csharp
// 下载进度更新（每帧触发）
downloader.DownloadUpdateCallback = (data) =>
{
    float progress          = data.Progress;              // 0.0 ~ 1.0
    int   currentCount      = data.CurrentDownloadCount;  // 已完成文件数
    long  currentBytes      = data.CurrentDownloadBytes;  // 已完成字节数
    int   totalCount        = data.TotalDownloadCount;
    long  totalBytes        = data.TotalDownloadBytes;
    // 更新进度条 UI
    progressBar.value = progress;
};

// 下载某个文件开始时触发
downloader.DownloadFileBeginCallback = (data) =>
{
    Debug.Log($"开始下载: {data.FileName}");
};

// 下载某个文件失败时触发（failedTryAgain 次全失败后才触发）
downloader.DownloadErrorCallback = (data) =>
{
    Debug.LogError($"下载失败: {data.FileName}, 错误: {data.Error}");
    // 可在此通知 UI 显示"下载失败，请重试"
};

// 全部下载结束时触发（成功或失败均触发）
downloader.DownloadFinishCallback = (data) =>
{
    Debug.Log($"下载结束，成功: {data.Succeed}");
};
```

## 开始下载 & 等待完成

```csharp
downloader.BeginDownload();
yield return downloader;

if (downloader.Status == EOperationStatus.Succeed)
{
    Debug.Log("所有文件下载成功！");
}
else
{
    Debug.LogError($"下载失败: {downloader.Error}");
    // 通知用户重试
}
```

## 暂停与恢复

```csharp
downloader.PauseDownload();   // 暂停（正在下载的文件会完成当前片段后停止）
downloader.ResumeDownload();  // 恢复
downloader.CancelDownload();  // 取消（不可恢复）
```

## 断点续传原理

YooAsset 使用 HTTP Range 请求实现断点续传：

1. 文件下载中途中断 → 本地保存 `.tmp` 临时文件
2. 重新下载时检测 `.tmp` 文件 → 发送 `Range: bytes=已下载大小-` 请求
3. 服务器返回剩余部分 → 追加写入 `.tmp` 文件
4. 校验完整 CRC/Hash → 重命名为正式文件

**文件校验**：下载完成后自动校验 CRC，不通过则删除重新下载。

---

## 下载优先级（边玩边下载）

当 `LoadAssetAsync` 发现资源不在本地时，会自动创建一个隐式下载任务。此时：

- 显式调用 `CreateResourceDownloader` 的任务和隐式任务**共用下载队列**
- 同一个 Bundle 不会被重复下载（内部有去重机制）

## 典型 UI 集成示例

```csharp
IEnumerator DownloadWithProgressUI(ResourcePackage package)
{
    var downloader = package.CreateResourceDownloader(10, 3);

    if (downloader.TotalDownloadCount == 0)
    {
        Debug.Log("无需下载，资源已是最新");
        yield break;
    }

    // 显示下载 UI
    float totalMB = downloader.TotalDownloadBytes / 1024f / 1024f;
    ShowDownloadUI($"发现更新，需下载 {totalMB:F1} MB");

    // 注册进度回调
    downloader.DownloadUpdateCallback = (data) =>
    {
        UpdateProgressBar(data.Progress);
        UpdateLabel($"{data.CurrentDownloadCount}/{data.TotalDownloadCount}");
    };
    downloader.DownloadErrorCallback = (data) =>
    {
        ShowRetryButton(data.FileName);
    };

    downloader.BeginDownload();
    yield return downloader;

    if (downloader.Status != EOperationStatus.Succeed)
    {
        ShowError("下载失败，请检查网络后重试");
        yield break;
    }

    HideDownloadUI();
    Debug.Log("下载完成！");
}
```
