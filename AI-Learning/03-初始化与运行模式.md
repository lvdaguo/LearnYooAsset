# 03 · 初始化与运行模式

## 四种运行模式总览

| 模式 | 枚举值 | 适用场景 | 需要打包？ |
|------|--------|----------|-----------|
| 编辑器模拟 | `EditorSimulateMode` | 编辑器调试，快速迭代 | 否 |
| 离线单机 | `OfflinePlayMode` | 资源全内置，无热更需求 | 是 |
| 联机热更 | `HostPlayMode` | 有 CDN，需要热更新 | 是 |
| WebGL | `WebPlayMode` | 网页/微信小游戏 | 是 |

---

## 第一步：初始化系统（全局一次）

```csharp
// 在游戏启动最早的地方调用，只调用一次
YooAssets.Initialize();

// 可传入自定义日志处理器
YooAssets.Initialize(new MyLogger());
```

---

## 第二步：创建并初始化资源包

### 模式 1 · 编辑器模拟模式

> 不需要打包，直接读取 AssetDatabase，适合日常开发。

```csharp
var package = YooAssets.CreatePackage("DefaultPackage");

// 自动模拟构建（读 AssetBundleCollector 配置）
var buildResult = EditorSimulateModeHelper.SimulateBuild("DefaultPackage");

var parameters = new EditorSimulateModeParameters();
parameters.EditorFileSystemParameters =
    FileSystemParameters.CreateDefaultEditorFileSystemParameters(
        buildResult.PackageRootDirectory);

var initOp = package.InitializeAsync(parameters);
yield return initOp;
```

**注意**：`EditorSimulateModeHelper.SimulateBuild` 只在 `UNITY_EDITOR` 下可用，打包后不存在。

---

### 模式 2 · 离线单机模式

> 资源全部打包进安装包的 StreamingAssets，不联网。

```csharp
var package = YooAssets.CreatePackage("DefaultPackage");

var parameters = new OfflinePlayModeParameters();
parameters.BuildinFileSystemParameters =
    FileSystemParameters.CreateDefaultBuildinFileSystemParameters();

var initOp = package.InitializeAsync(parameters);
yield return initOp;
```

---

### 模式 3 · 联机热更模式（最常用）

> 安装包内有首包资源，更新资源从 CDN 下载到本地缓存。

```csharp
var package = YooAssets.CreatePackage("DefaultPackage");

// 实现 IRemoteServices：告诉框架资源文件的 CDN 地址
IRemoteServices remoteServices = new RemoteServices(
    "http://your-cdn.com/v1.0",   // 主 CDN
    "http://your-backup.com/v1.0" // 备用 CDN
);

var parameters = new HostPlayModeParameters();
// 内置文件系统（StreamingAssets 中的首包）
parameters.BuildinFileSystemParameters =
    FileSystemParameters.CreateDefaultBuildinFileSystemParameters();
// 缓存文件系统（下载后存到本地）
parameters.CacheFileSystemParameters =
    FileSystemParameters.CreateDefaultCacheFileSystemParameters(remoteServices);

var initOp = package.InitializeAsync(parameters);
yield return initOp;
```

**IRemoteServices 实现**：

```csharp
public class RemoteServices : IRemoteServices
{
    private readonly string _main;
    private readonly string _fallback;

    public RemoteServices(string main, string fallback)
    {
        _main = main;
        _fallback = fallback;
    }

    // 主 CDN：返回完整文件 URL
    public string GetRemoteMainURL(string fileName) => $"{_main}/{fileName}";

    // 备用 CDN：主 CDN 失败时使用
    public string GetRemoteFallbackURL(string fileName) => $"{_fallback}/{fileName}";
}
```

---

### 模式 4 · WebGL 模式

```csharp
var parameters = new WebPlayModeParameters();
parameters.WebServerFileSystemParameters =
    FileSystemParameters.CreateDefaultWebServerFileSystemParameters();

var initOp = package.InitializeAsync(parameters);
yield return initOp;
```

微信小游戏需要使用扩展包的专用 FileSystem（`WechatFileSystemCreater`）。

## 初始化参数基类（通用配置）

所有 `InitializeParameters` 的子类都继承了以下公共参数：

```csharp
// 同时加载 Bundle 的最大并发数（默认无限制）
parameters.BundleLoadingMaxConcurrency = 10;

// 引用计数归零时自动卸载 Bundle（默认 false，需手动调用 UnloadUnusedAssets）
parameters.AutoUnloadBundleWhenUnused = false;

// WebGL 强制同步加载（默认 false）
parameters.WebGLForceSyncLoadAsset = false;
```

---

## 初始化结果判断

```csharp
var initOp = package.InitializeAsync(parameters);
yield return initOp;

if (initOp.Status == EOperationStatus.Succeed)
{
    Debug.Log("初始化成功");
}
else
{
    Debug.LogError($"初始化失败: {initOp.Error}");
}
```

---

## 多包管理

一个项目可以创建多个 Package，各自独立管理：

```csharp
YooAssets.CreatePackage("MainPackage");   // 主包
YooAssets.CreatePackage("DLCPackage");    // DLC 包
YooAssets.CreatePackage("AudioPackage");  // 音频包

// 设置默认包（调用 YooAssets.LoadAssetAsync 时使用）
YooAssets.SetDefaultPackage(YooAssets.GetPackage("MainPackage"));
```
