# 01 · 入门概览

## YooAsset 是什么

YooAsset 是一套 Unity 3D **资源管理系统**，核心解决三件事：

1. **资源打包** — 按规则把 Assets 打成 AssetBundle
2. **版本管理 / 热更新** — 对比服务器版本，下载差量更新
3. **运行时加载** — 统一 API 加载资源对象、场景、原生文件

它已在多款百万 DAU 产品上验证，支持 Android / iOS / PC / WebGL / 微信小游戏 / 抖音小游戏。

---

## 核心能力速览

| 能力 | 说明 |
|------|------|
| 可寻址资源 | 用路径或地址加载，不关心 Bundle 内部结构 |
| 引用计数卸载 | 自动追踪资源引用，计数为零时安全卸载 |
| 边玩边下载 | 加载时本地缺包 → 自动从 CDN 下载再加载 |
| 多线程下载 | 断点续传、自动校验、失败重试 |
| 多模式切换 | 编辑器模拟 / 离线 / 联机 / WebGL，不改业务代码 |
| 分布式构建 | 多工程分别打包，合并到一个 Manifest |
| 两条构建管线 | 传统 BuiltinBuildPipeline 和 ScriptableBuildPipeline(SBP) |

## 最小使用流程（三步）

```csharp
// 1. 初始化系统（全局一次）
YooAssets.Initialize();

// 2. 创建并初始化资源包
var package = YooAssets.CreatePackage("DefaultPackage");
var parameters = new OfflinePlayModeParameters();
parameters.BuildinFileSystemParameters =
    FileSystemParameters.CreateDefaultBuildinFileSystemParameters();
var initOp = package.InitializeAsync(parameters);
yield return initOp;

// 3. 加载资源
var handle = package.LoadAssetAsync<GameObject>("Assets/Prefabs/Enemy.prefab");
yield return handle;
var go = handle.InstantiateSync();
```

## 与 Addressables 的对比

| 对比项 | YooAsset | Unity Addressables |
|--------|----------|--------------------|
| 学习曲线 | 概念清晰，API 简洁 | 概念较多，配置复杂 |
| 热更新 | 内置完整热更流程 | 需要额外方案 |
| 多平台小游戏 | 官方支持微信/抖音 | 不支持 |
| 分布式构建 | 原生支持 | 有限支持 |
| 开源 | MIT | 商业许可 |

## 项目依赖（package.json）

```json
"dependencies": {
    "com.unity.scriptablebuildpipeline": "1.21.25",
    "com.unity.modules.assetbundle": "1.0.0",
    "com.unity.modules.unitywebrequest": "1.0.0",
    "com.unity.modules.unitywebrequestassetbundle": "1.0.0"
}
```

SBP 是可选构建管线，其余三个是 Unity 内置模块必选项。
