# 04 · 热更新完整流程

## 热更新的本质

```
本地 Manifest ──────┐
                    ├─→ 对比差异 → 下载缺失 Bundle → 更新本地 Manifest
服务器 Manifest ────┘
```

热更新 = **拉取新 Manifest** + **下载差量 Bundle**，整个游戏逻辑代码不需要任何修改。

---

## 完整状态机流程（来自 Space Shooter Sample）

```
FsmInitializePackage          ← 初始化包（决定用哪种模式）
        ↓
FsmRequestPackageVersion      ← 向服务器查询最新版本号
        ↓
FsmUpdatePackageManifest      ← 下载并应用新版本 Manifest
        ↓
FsmCreateDownloader           ← 统计需要下载的 Bundle
        ↓  (有新文件)
FsmDownloadPackageFiles       ← 实际下载
        ↓
FsmDownloadPackageOver        ← 下载完成校验
        ↓
FsmClearCacheBundle           ← 清理旧版本缓存
        ↓
FsmStartGame                  ← 进入游戏
```

**OfflinePlayMode** 不走版本请求和下载步骤，初始化完毕后直接进入游戏。

---

## 逐步代码详解

### Step 1 · 请求版本号

```csharp
var package = YooAssets.GetPackage("DefaultPackage");
var versionOp = package.RequestPackageVersionAsync();
yield return versionOp;

if (versionOp.Status == EOperationStatus.Succeed)
{
    string latestVersion = versionOp.PackageVersion;
    // 继续下一步...
}
```

框架通过 `IRemoteServices.GetRemoteMainURL("PackageManifest_DefaultPackage_hash.bytes")` 访问服务器，返回版本字符串。

---

### Step 2 · 更新 Manifest

```csharp
var manifestOp = package.UpdatePackageManifestAsync(latestVersion);
yield return manifestOp;

// manifestOp.Status == Succeed → 新 Manifest 已写入本地缓存
```

这一步会从服务器下载新版本的清单文件，并与本地对比，更新内存中的 `PackageManifest`。

---

### Step 3 · 创建下载器，统计差量

```csharp
// 下载整个包所有缺失的 Bundle
int downloadingMaxNum = 10;  // 最大并发下载数
int failedTryAgain   = 3;   // 失败重试次数

var downloader = package.CreateResourceDownloader(downloadingMaxNum, failedTryAgain);

// 按标签下载（分包场景）
// var downloader = package.CreateResourceDownloader(new string[]{"level1"}, 10, 3);

// 查看统计信息（用于显示下载提示 UI）
int   totalCount = downloader.TotalDownloadCount;  // 需要下载的文件数
long  totalBytes = downloader.TotalDownloadBytes;  // 需要下载的总字节数

if (totalCount == 0)
{
    // 本地资源是最新的，无需下载
}
```

---

### Step 4 · 开始下载

```csharp
// 注册回调
downloader.DownloadUpdateCallback = OnDownloadProgress;
downloader.DownloadErrorCallback  = OnDownloadError;

downloader.BeginDownload();
yield return downloader;  // 等待所有文件下载完成

if (downloader.Status != EOperationStatus.Succeed)
{
    // 下载失败处理
}
```

**进度回调**：

```csharp
private void OnDownloadProgress(DownloadUpdateData data)
{
    float progress = data.Progress;            // 0.0 ~ 1.0
    int   currentCount = data.CurrentDownloadCount;
    long  currentBytes = data.CurrentDownloadBytes;
}

private void OnDownloadError(string fileName, string error)
{
    Debug.LogError($"下载失败: {fileName}, {error}");
}
```

---

### Step 5 · 清理旧缓存（可选）

```csharp
// 清除所有未被当前 Manifest 引用的旧 Bundle
var clearOp = package.ClearCacheFilesAsync(EFileClearMode.ClearUnusedBundleFiles);
yield return clearOp;

// 其他清理模式：
// EFileClearMode.ClearAllBundleFiles          - 清除所有缓存
// EFileClearMode.ClearBundleFilesByTags       - 按标签清除
// EFileClearMode.ClearBundleFilesByLocations  - 按资源地址清除（v2.3.18 新增）
```

## 错误重试模式（UI 交互）

实际项目中，用户可能网络不好导致失败，需要给用户"重试"按钮：

```csharp
// 1. 监听失败事件
// 2. 显示"重试"按钮
// 3. 用户点击后发送事件，状态机切换回对应节点
// 例：Space Shooter 中
UserEventDefine.UserTryInitialize.SendEventMessage();        // 重试初始化
UserEventDefine.UserTryRequestPackageVersion.SendEventMessage(); // 重试版本请求
UserEventDefine.UserTryUpdatePackageManifest.SendEventMessage(); // 重试清单更新
UserEventDefine.UserTryDownloadWebFiles.SendEventMessage();  // 重试下载
```

## CDN 服务器目录规范

构建输出的目录结构需要按平台上传到 CDN：

```
CDN 根目录
└── Android/
    └── v1.0/
        ├── PackageManifest_DefaultPackage_xxx.bytes  ← Manifest 文件
        ├── PackageManifest_DefaultPackage_xxx.hash   ← 版本哈希
        └── xxxxxx.bundle                             ← Bundle 文件
```

`IRemoteServices` 返回的 URL 拼接规则：
```
GetRemoteMainURL(fileName) = "{hostServer}/{fileName}"
// 实际请求：http://cdn.com/v1.0/PackageManifest_DefaultPackage_abc123.hash
```

## 热更新流程总结图

```
游戏启动
  │
  ├─[首次/离线] 直接进游戏（OfflinePlayMode）
  │
  └─[联机] RequestPackageVersionAsync
              │  失败 → 提示重试
              ↓
         UpdatePackageManifestAsync
              │  失败 → 提示重试
              ↓
         CreateResourceDownloader
              │  无差量 → 直接进游戏
              ↓
         BeginDownload
              │  失败 → 提示重试
              ↓
         ClearCacheFilesAsync（可选）
              ↓
         进入游戏
```
