# 05 · 资源加载系统

## Handle 体系

所有加载操作都返回一个 **Handle（句柄）**，Handle 实现了 `IEnumerator` 和 `IDisposable`：

```
HandleBase (抽象基类)
  ├── AssetHandle       ← 加载单个资源（Prefab、Texture、ScriptableObject…）
  ├── SceneHandle       ← 加载场景
  ├── RawFileHandle     ← 加载原生文件（JSON、音频、视频…）
  ├── SubAssetsHandle   ← 加载子资源（Sprite Sheet 中的多个 Sprite）
  └── AllAssetsHandle   ← 加载文件夹内所有资源
```

## 资源定位地址（Location）

默认使用**资源完整路径**作为地址：

```csharp
"Assets/Prefabs/Enemy.prefab"
"Assets/UI/Textures/icon_home.png"
```

如果在 Collector 配置中启用了**可寻址模式**，可以使用自定义短地址：

```csharp
"Enemy"         // 对应 Assets/Prefabs/Enemy.prefab
"icon_home"     // 对应 Assets/UI/Textures/icon_home.png
```

## AssetHandle · 加载单个资源

### 异步加载（推荐）

```csharp
// 泛型版（最常用）
var handle = package.LoadAssetAsync<GameObject>("Assets/Prefabs/Enemy.prefab");
yield return handle;

if (handle.Status == EOperationStatus.Succeed)
{
    // 实例化 GameObject
    var go = handle.InstantiateSync();
    
    // 或者获取资源对象本身（不实例化）
    var prefab = handle.GetAssetObject<GameObject>();
}

// 用完后必须释放，否则 Bundle 无法卸载！
handle.Release();
```

### 实例化时传参

```csharp
// 指定父节点
var go = handle.InstantiateSync(parentTransform);

// 指定位置和旋转
var go = handle.InstantiateSync(Vector3.zero, Quaternion.identity);

// 指定位置、旋转、父节点
var go = handle.InstantiateSync(Vector3.zero, Quaternion.identity, parentTransform);
```

### 同步加载

```csharp
var handle = package.LoadAssetSync<AudioClip>("Assets/Audio/bgm.mp3");
var clip = handle.GetAssetObject<AudioClip>();
// 用完释放
handle.Release();
```

**实现原理**：`LoadAssetSync` 和 `LoadAssetAsync` 内部走同一个函数，只是多一步 `WaitForAsyncComplete()` 强制立即完成。**四种运行模式都支持同步加载**。

**慎用场景**：
- 会阻塞主线程，大文件容易掉帧
- 联机模式下如果资源还没下载完，同步加载会立刻失败（不会等下载）
- WebGL 平台浏览器限制，同步加载可能不工作

优先用异步加载，同步加载只在"明确知道资源小且本地存在"时用。

### 回调方式

```csharp
var handle = package.LoadAssetAsync<Sprite>("Assets/UI/icon.png");
handle.Completed += (h) =>
{
    var sprite = h.GetAssetObject<Sprite>();
    image.sprite = sprite;
};
```

## SceneHandle · 加载场景

```csharp
// 异步加载场景
var handle = package.LoadSceneAsync("Assets/Scenes/Battle.unity",
    LoadSceneMode.Single);          // Single 或 Additive
yield return handle;

// 卸载场景
yield return handle.UnloadAsync();
```

> 场景 Handle 不调用 `Release()`，而是调用 `UnloadAsync()` 卸载。

## RawFileHandle · 加载原生文件

原生文件是指不经过 AssetBundle 处理的文件（JSON、二进制配置、视频等）。

```csharp
var handle = package.LoadRawFileAsync("Assets/Config/config.json");
yield return handle;

// 读取为文本
string json = handle.GetRawFileText();

// 读取为字节数组
byte[] bytes = handle.GetRawFileData();

// 获取文件路径（从磁盘路径加载）
string path = handle.GetRawFilePath();

handle.Release();
```

## SubAssetsHandle · 加载子资源

常用于 Sprite Atlas 中加载多个 Sprite：

```csharp
var handle = package.LoadSubAssetsAsync<Sprite>("Assets/UI/Atlas.png");
yield return handle;

// 获取所有子资源
Sprite[] sprites = handle.GetSubAssetObjects<Sprite>();

// 按名字获取
Sprite icon = handle.GetSubAssetObject<Sprite>("icon_home");

handle.Release();
```

## AllAssetsHandle · 加载文件夹所有资源

```csharp
// 加载目录下所有 Prefab
var handle = package.LoadAllAssetsAsync<GameObject>("Assets/Prefabs");
yield return handle;

UnityEngine.Object[] allAssets = handle.AllAssetObjects;
handle.Release();
```

## 边玩边下载（LoadAssetAsync 自动触发下载）

联机模式下，如果资源所在的 Bundle 本地不存在：

```
LoadAssetAsync("Assets/Level2/Boss.prefab")
    → 发现 Bundle 不在本地
    → 自动从 CDN 下载 Bundle
    → 下载完成后加载资源
    → Handle 变为 Succeed
```

可通过 Handle 的进度查询下载状态：

```csharp
var handle = package.LoadAssetAsync<GameObject>("Assets/Level2/Boss.prefab");

// 在 Update 中轮询进度
while (!handle.IsDone)
{
    var downloadStatus = handle.GetDownloadStatus();
    float progress = downloadStatus.Progress;
    yield return null;
}
```

## 资源卸载

### 方式 1：释放 Handle（主动卸载）

```csharp
handle.Release();   // 等价于 handle.Dispose()
// 引用计数 -1，归零时自动卸载 Bundle
```

### 方式 2：卸载全部未使用资源

```csharp
// 卸载引用计数为 0 的所有 Bundle
var op = package.UnloadUnusedAssetsAsync();
yield return op;
```

### 方式 3：强制卸载所有资源（慎用）

```csharp
// 强制释放所有资源，包括正在使用的（会导致资源丢失）
var op = package.UnloadAllAssetsAsync();
yield return op;
```

## 常见错误

| 错误 | 原因 | 解决 |
|------|------|------|
| `Handle is invalid` | 调用 Release 后继续使用 Handle | 释放后置 null |
| 资源一直占内存 | 忘记调用 Release | 配合 `using` 语句或 OnDestroy 释放 |
| 同步加载卡顿 | 主线程被 `WaitForAsyncComplete` 阻塞 | 改用异步加载，或确认资源小且本地存在 |
| 联机模式下同步加载失败 | 资源还没下载完，同步无法等待下载 | 先通过 Downloader 把资源下载到本地再同步加载 |
| 找不到资源 | Location 路径写错或未配置 Collector | 检查地址、检查 Collector 设置 |

## 用 using 自动释放

```csharp
// Handle 实现了 IDisposable，可用 using 自动释放
using (var handle = package.LoadAssetAsync<AudioClip>("Assets/Audio/bgm.mp3"))
{
    yield return handle;
    AudioSource.PlayClipAtPoint(handle.GetAssetObject<AudioClip>(), Vector3.zero);
}
// 离开 using 块自动 Release
```
